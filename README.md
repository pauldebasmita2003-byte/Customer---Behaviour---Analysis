# Customer Behaviour Analysis

## Objective
Analyze customer transactions and behavior to identify customer segments, purchase patterns, and churn risks using Python.

## Dataset
Customer Behavior Analysis Dataset (Kaggle)

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
- Data Cleaning
- Exploratory Data Analysis (EDA)
- RFM Analysis
- Customer Segmentation
- Correlation Analysis
- Business Recommendations

## Key Findings
- Clothing was the most purchased product category.
- Credit Card was the most preferred payment method.
- Customer purchases remained relatively stable over time.
- RFM analysis identified High Value, Loyal, Potential, At Risk, and Low Value customer segments.

## Business Recommendations
- Retain High Value customers through loyalty programs.
- Convert Potential customers into Loyal customers.
- Reduce customer churn using targeted retention strategies.
- Increase sales of Electronics and Home products.
- Continue using customer segmentation for personalized marketing.
